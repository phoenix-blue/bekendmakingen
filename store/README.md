# TSC Store-materiaal

Deze map bevat privacy-veilige voorbeeldafbeeldingen voor de TSC Store. Ze
gebruiken fictieve gegevens en tonen geen adres of instellingen van een echte
Toon. Voor een testopname in de Store:

1. kopieer `bekendmakingen_screenshot_1.png` tot en met
   `bekendmakingen_screenshot_3.png` naar de hoofdmap van de branch `test` van
   `ToonSoftwareCollective/toonstore_AppRepository`;
2. voeg de inhoud van `../ToonRepo-entry.xml` toe aan `ToonRepo.xml` op die
   branch;
3. controleer de vermelding eerst met de testmodus van ToonStore.

Deze repository publiceert de app alleen op de eigen GitHub-testbranch en
wijzigt de officiële TSC Store-repository niet automatisch.
